# Model Card

## 模型名称

Physical Fitness Aging Index v1.0 与 M0-BA-scale-0.1-exploratory。

## 用途

用标准化体测成绩生成年龄/性别标准化功能缺损评分 FAI，并用约定年龄尺度生成探索性 BA。适用于研究数据分析、群体描述和纵向功能变化研究。

## 训练概要

- 参考模型按性别分层。
- 使用实际检测日期与出生日期计算精确年龄。
- 以 Oneid 为分组单位划分训练、验证和测试集，避免同一人跨集泄漏。
- 单项参考使用三次惩罚 B 样条 Gaussian location-scale 模型。
- 完整七项 FAI 在训练参考中标准化为中心 50、标准差约 10。
- BA 换算使用训练集年龄标准差 4.3608481236 年/FAI SD。
- 完整参考的训练人数和曲线支持数据保存在冻结 JSON 模型中。

## 主要范围

- 年龄参考曲线：20–44.999 岁。
- 完整七项主要参考：20–39 岁。
- 25–39 岁为样本支持较稳定的主要区间。
- FAI 与 BA 不强制裁剪到固定数值范围。

## 非预期用途

- 不用于医疗诊断、临床分级或治疗决策。
- 不应将个体 BA 解释为已验证的绝对生物学年龄。
- 不应把 BA 降低直接解释为“逆龄”或疾病风险下降。
- 未经验证的测试单位、测试规程或人群不应直接套用。

## 已知局限

- 尚未完成外部独立队列验证。
- 尚未完成健康结局、死亡、疾病或干预反应验证。
- 缺项 BA 的区间只反映桥接模型验证残差，不包含测量误差、参考模型和年龄尺度的全部不确定性。
- 40 岁及以上完整体测项目的数据支持不足，因此输出必须视为范围外延伸。
- 性别字段用于选择数据中建立的参考曲线，不是对性别身份的临床定义。

## 版本和可重现性

- 参考模型：`pfa_v1.json`, version `1.0.0-research`。
- BA 尺度：`m0_ba_scale.json`, version `M0-BA-scale-0.1-exploratory`。
- 缺项桥接：`annual_bridge_models.json`, version `1.0-annual-exploratory`。
- 模型文件校验值见根目录 `SHA256SUMS.txt`。
