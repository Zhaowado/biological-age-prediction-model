# 方法学说明

## 1. 年龄和性别特异参考

每个体测项目在男性和女性中分别建立年龄参考分布。均值和对数标准差采用三次 B 样条表示，参数已冻结在 `models/pfa_v1.json`。连续年龄 `a` 先限定到 20–44.999 岁的参考域，然后得到单项参考均值 `mu_sj(a)` 和标准差 `sigma_sj(a)`。

对单脚站立、俯卧撑和仰卧起坐使用 `log(1+x)` 变换，对反应时使用 `log(x)` 变换，其他项目使用原始尺度。

## 2. 单项功能缺损

对性别 `s`、项目 `j` 和年龄 `a`：

```text
z_j = [T_j(x_j) - mu_sj(a)] / sigma_sj(a)
d_j = -direction_j * z_j
```

`direction_j=+1` 表示越大越好，反应时的 `direction_j=-1`。因此所有 `d_j` 都统一为数值越大、功能缺损越明显。

## 3. 领域和 FAI 合成

七项共同指标被分为力量、爆发力、肺功能、心血管耐力、柔韧性和感觉运动六个领域。单脚站立和反应时先在感觉运动领域内平均，然后六个领域等权平均，防止某个领域因包含更多项目而自动获得更高权重。

```text
domain_d = mean(d_j in domain d)
raw_deficit = mean(domain_d)
FAI = 50 + 10 * (raw_deficit - training_center) / training_SD
```

FAI 中心为 50，约 10 分对应训练参考的 1 个标准差。FAI 没有 0–100 的强制边界。

## 4. BA 年龄尺度

```text
BA = A + 0.43608481236232405 * (FAI - 50)
BA_gap = BA - A
```

`A` 是年龄锚点：优先使用 `RA_anchor` 或 `RA`，否则使用出生日与检测日期推导的精确年龄，再否则使用 `age`。当年龄完全缺失时，程序使用训练集平均年龄 29.0075988361 岁作为显式假设，并标为低可信度。

0.4360848124 年/FAI 分等于 4.3608481236 年/FAI 标准差。它用训练集年龄标准差设定量纲，不代表通过年龄预测优化获得的回归系数。

## 5. 缺项桥接

对实际数据中出现过的缺项组合，在原始训练集中人为遮蔽同样的项目，并以完整七项 FAI 为目标建立分性别岭回归：

```text
FAI_bridge = beta_0 + sum(beta_j * d_j)
```

惩罚强度由独立验证集选择，系数和验证残差分位数冻结在 `models/annual_bridge_models.json`。缺项桥接仅用于已支持的组合；新的缺失模式返回 `unsupported_missingness_pattern`，不会隐式填造结果。

## 6. 按年聚合

同一人同一年可有多次检测。对每个指标独立取该年最后一次通过物理边界 QC 的值，而不是只保留最后一次访视整行。这样可以避免后续单项复测覆盖同年早期完整体测。

## 7. 可信度标记

只有同时满足以下条件时，`BA_low_confidence=False`：

1. 七项共同指标完整；
2. 性别有记录；
3. 有可用的精确年龄；
4. 年龄在 20–39 岁主参考范围。

低可信度不等于计算错误，表示该结果依赖缺项桥接、人口学假设或参考域边界延伸。
